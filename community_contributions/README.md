# Community contributions

Work shared by students of the course, one folder each, added by pull request.

Small, self-contained pieces work best: a skill, a hook, a subagent, a `REVIEW.md`, a CI workflow, or a guide for a coding agent the course doesn't cover. To share your own build of Accountable, add one Markdown file with what you built, a screenshot or two, your takeaways and a link to your build.

The steps are in [course/for_agents/AGENT_GIT_GUIDE.md](../course/for_agents/AGENT_GIT_GUIDE.md), and your coding agent can take you through them.

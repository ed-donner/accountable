Follow these coding guidelines:

- For description text with 5 or fewer sentences, have each sentence in its own line.
- Be thoughtful and careful about labels and naming things, so that code is expressive and easy to read. 
- Don't comment out unused code, delete it.
- Favor short functions and methods with only one purpose.
- Make code readable so that only brief comments are needed, and primarily about the Why.
- Ensure text and code are only what is necessary, do not add in low value descriptions or filler words. 
- Clean abstractions with clear separation of concerns, but don't abstract before it's needed.
- Avoid brittle tests that are tied to implementation specifics.
